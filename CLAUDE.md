## Build and Test Commands
- Restore dependencies: `dotnet restore`
- Build solution: `dotnet build`
- Run tests: `dotnet test`
- Validate packaged XML docs: `./build/Test-PackageDocumentation.ps1`

## Test Authoring Guidance
- When writing HTTP response tests with this library, follow [Prompt for AI agents and rapid test authoring](readme.md#prompt-for-ai-agents-and-rapid-test-authoring).
